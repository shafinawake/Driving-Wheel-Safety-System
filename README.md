# Driving-Wheel-Safety-System
It's a project for the course "Digital Logic Design." In this project, we used basic gates to create a system that will calculate how many fingers are touching the driving wheel. In this case, we used switches to represent the driving wheel. 

This circuit can me made in many ways, and some of those can be really complicated. So we tried our best to make the circuit as simple as possible.

We considered each finger to correspond to another finger of the other hand so that we could have 5 inputs instead of 10. As a result, we have a fairly simple circuit, then we simplified the circuit even more by using a logical MASK with AND and OR gates.
